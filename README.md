Un profil Maven (activé avec mvn -P prod) agit au moment du build : il permet de modifier la compilation, les dépendances, les plugins ou les variables selon l’environnement (par exemple inclure/exclure certains modules ou changer une configuration de packaging). En revanche, un profil Spring (activé avec --spring.profiles.active=prod) agit au moment de l’exécution de l’application : il permet de charger des configurations spécifiques (fichiers application-prod.yml, beans, paramètres de connexion, etc.) en fonction de l’environnement. En résumé, Maven gère comment l’application est construite, tandis que Spring gère comment elle se comporte une fois lancée.
